# SkillHive — Design Context

## Design Context

### Users
Developers, AI builders, and Web3 power users who want to monetize or consume AI agent skills on Solana. They arrive with a clear job to do — browse/call a skill, or register their own — and expect the interface to get out of their way. Hackathon judges are also a key audience: they need to grasp the value proposition in under 10 seconds. Secondary audience: non-technical creators who want to publish Prompt Skills without writing code.

### Brand Personality
**Precise, powerful, open.**
Tone: confident but not arrogant. Approachable without being cutesy. The mascot (robot bee in a hexagon) gives permission for a touch of personality — use it sparingly as a brand anchor, not a recurring decoration. Think "the friendly expert": Jupiter's clarity, Raydium's speed, but without the DeFi heaviness.

### Aesthetic Direction
**Reference:** clawhub.ai — clean card grid, crisp typography, developer-friendly information density, dark background with structured whitespace. **Not** generic "one AI spot" style: no floating gradient blobs, no starfield backgrounds, no ChatGPT-clone layouts, no excessive glow halos.

**Color palette — sourced directly from the SkillHive logo (Solana-inspired):**
```
--swarm-purple:   #9945FF   (Solana purple — primary brand)
--swarm-green:    #14F195   (Solana green — accent, success, earnings)
--swarm-gradient: linear-gradient(135deg, #9945FF, #14F195)
--bg-base:        #0f1117   (deep charcoal, near-black)
--bg-card:        #161b27   (card surface)
--bg-elevated:    #1e2435   (hover/elevated surface)
--border-subtle:  #2a3147   (default border)
--border-active:  #9945FF40 (purple-tinted active border)
--text-primary:   #F8FAFC   (near-white)
--text-secondary: #8B9BB4   (muted slate-blue)
--text-tertiary:  #4A5568   (disabled / placeholder)
```

**Typography:** Space Grotesk (headings — slightly quirky, technical, non-generic) + Inter (body — maximum legibility). Import via `next/font/google`. Avoid system font stack — it reads as unfinished.

**Micro-interactions only:**
- Card hover: `translateY(-2px)` + subtle purple border glow (`box-shadow: 0 0 0 1px #9945FF40`)
- Button press: `scale(0.97)` via `active:scale-[0.97]`
- Badge/tag: gentle opacity transition on hover
- Input focus: purple ring (`ring-[#9945FF]`)
- No page transitions, no skeleton-to-content morphs, no scroll-triggered reveals

**Spacing & shape:**
- Border radius: `12px` cards, `8px` inputs/buttons, `6px` badges
- Card padding: `24px`
- Grid gap: `16px` (compact but breathable)
- Max content width: `1200px`

### Design Principles
1. **Density with clarity** — Show meaningful data per card (name, tier, price, reputation, calls) without overwhelming. Every pixel earns its place.
2. **Solana colors own the personality** — Purple and green are the only "loud" colors. Everything else is neutral dark slate. Don't add blue, orange, or other hues.
3. **No generic AI aesthetic** — No blob gradients, no starfields, no "chat" metaphors. This is a marketplace, not a chatbot.
4. **Micro-interactions, not animations** — Hover states and focus rings communicate interactivity. Motion is reserved for functional feedback (loading spinners, toast entries).
5. **Accessible by default** — All interactive elements meet WCAG AA contrast. Purple-on-dark (#9945FF on #0f1117) passes at large sizes; pair with white text for small elements.

## Font Setup (add to layout.tsx)
```typescript
import { Space_Grotesk, Inter } from 'next/font/google'

const spaceGrotesk = Space_Grotesk({
  subsets: ['latin'],
  variable: '--font-heading',
  weight: ['400', '500', '600', '700'],
})

const inter = Inter({
  subsets: ['latin'],
  variable: '--font-body',
})
// Apply: className={`${spaceGrotesk.variable} ${inter.variable} font-sans`} on <body>
```

Add to `tailwind.config.ts`:
```typescript
fontFamily: {
  sans: ['var(--font-body)', 'system-ui', 'sans-serif'],
  heading: ['var(--font-heading)', 'system-ui', 'sans-serif'],
}
```
